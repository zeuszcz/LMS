# Software Requirements Specification — YES LMS

Версия: 0.1 (draft)
Дата: 2026-04-27
Статус: alpha — уточняется после Discovery с заказчиком.

## 1. Цель

Заменить разрозненные инструменты (бумажные журналы, Excel расписания, Zoom, отдельный 1С для оплат) единой LMS-платформой для лингвистического центра YES Center с покрытием ключевых процессов: каталог курсов, набор групп, расписание, проведение и журнал уроков, домашние задания, прогресс ученика, оплаты, родительский кабинет, видеоуроки, экзамены, B2B-портал.

## 2. Контекст и стейкхолдеры

| Стейкхолдер          | Интерес                                                              |
|----------------------|----------------------------------------------------------------------|
| Студент              | Удобный кабинет с уроками, прогрессом, домашками                     |
| Преподаватель        | Журнал, материалы курса, проверка ДЗ, чат                            |
| Родитель             | Прогресс ребёнка, оплаты, чат с преподавателем                        |
| Методист             | Каталог курсов, контроль качества, отчёты                            |
| Руководитель филиала | Расписание филиала, KPI, ресурсы                                      |
| Администрация YES    | Финансы, аналитика по сети, маркетинговые акции                       |
| Корп. клиенты (B2B)  | Прогресс сотрудников, отчёты, white-label                             |

## 3. Целевая аудитория и масштабы

- 20+ филиалов в Москве, МО, Владимирской области.
- Ожидаемое количество активных студентов: 5 000–8 000.
- Преподавателей: 200–300.
- Параллельных уроков в пик: ~300.
- Языки: en/de/fr/it/es/zh/ja/ko.
- Возрастные группы: kids (3–11), teens (12–17), adults (18+).

## 4. Функциональные требования

См. полный roadmap в [`docs/roadmap.md`](roadmap.md). Ниже — высокоуровневые модули.

### 4.1. Auth & RBAC (MVP)
- Регистрация только через приглашение (admin/methodist выдаёт).
- Email + password или phone + SMS-код (Phase 2).
- Refresh-токены, logout-all-sessions (Phase 2).
- Роли: student, teacher, parent, methodist, branch_manager, admin, b2b_coordinator.
- Branch-scoped permissions.

### 4.2. Каталог курсов (MVP)
- CRUD курсов методистом / админом.
- Версионирование (Phase 2): новая версия не ломает активные группы.
- Фильтры: язык, уровень CEFR, возрастная группа, формат.
- Публикация / черновик (`published_at`).

### 4.3. Группы и расписание (MVP)
- Группа = курс + филиал + преподаватель + расписание.
- RRULE-подобные слоты (день недели × время).
- Лимит студентов, статус (planned/active/finished/cancelled).
- Конфликт-детектор (преподаватель / аудитория) — Phase 1 week 10+.

### 4.4. Журнал и посещаемость (MVP)
- Преподаватель открывает журнал на день урока.
- Отметки: present / late / absent / excused + балл участия 1–5.
- Заметка для методиста.
- Закрытие урока → списание кредитов (Phase 2), parent-summary, обновление прогресса.

### 4.5. Домашние задания (MVP)
- Типы: quiz (auto-check), writing (manual), speaking (audio upload), reading.
- Дедлайн, попытки.
- Грейдинг с рубрикой.
- AI-черновик фидбека (Phase 3) — преподаватель редактирует.

### 4.6. Прогресс ученика (MVP partial → Phase 2 full)
- Skill scores: listening / reading / writing / speaking / grammar / vocab.
- Текущий CEFR + траектория к целевому уровню.
- История ДЗ и оценок.

### 4.7. Родительский кабинет (MVP)
- Карточка каждого ребёнка: посещаемость, домашки, оплаты (read-only), сообщения.
- Чат с преподавателем (Phase 2).

### 4.8. Уведомления (MVP)
- Каналы: email + Telegram-бот (MVP), SMS (fallback, Phase 2), push (Phase 2).
- События: напоминание об уроке (T-24h, T-30m), сдана/просрочена ДЗ, оплата, перенос.
- Outbox-паттерн с retry.

### 4.9. Оплаты (Phase 2)
- Эквайринг: ЮKassa (MVP-выбор), recurring, СБП, банковские карты, Apple/Google Pay.
- Абонементы / пакеты часов / разовые уроки.
- Lesson credit ledger (append-only).
- Заморозка, отмена с правилом «<24h», возврат.
- 54-ФЗ чеки через провайдера.

### 4.10. 1С интеграция (Phase 2)
- Двусторонняя синхронизация студентов и платежей.
- Импорт из CSV в MVP, REST API в Phase 2.

### 4.11. Видеоуроки (Phase 2)
- LiveKit self-hosted в Yandex Cloud RU.
- 1:1 и групповые до 12 участников.
- Запись с согласия (для несовершеннолетних — согласие родителя).
- Виртуальная доска, экран преподавателя.

### 4.12. Mock-экзамены (Phase 3)
- Cambridge KET/PET/FCE/CAE, IELTS, ЕГЭ/ОГЭ.
- Anti-cheat: focus-loss, copy-paste lock, optional online proctoring.
- Auto-check objective частей; рубрика-оценка writing/speaking.
- Прогноз готовности к экзамену.

### 4.13. B2B-портал (Phase 4)
- Tenant-per-company.
- SSO (SAML/OIDC).
- Корпоративный куратор: список сотрудников, прогресс, отчёты.
- White-label опциональный.

### 4.14. Маркетплейс летних программ (Phase 4)
- Каталог Summer Vibes, лагерей, обучения за рубежом.
- Анкеты, онлайн-оплата.

## 5. Нефункциональные требования

### 5.1. Производительность
- p95 API < 300 мс (без интеграционных вызовов).
- p95 загрузка SPA < 2 с при 4G.
- Поддержка 300 конкурентных видеоучастников (Phase 2).

### 5.2. Доступность
- SLA 99.5% в рабочие часы (08:00–22:00 MSK).
- RTO 4 часа, RPO 15 минут (Phase 2 backup-стратегия).

### 5.3. Безопасность
- HTTPS only, HSTS.
- OWASP Top-10 — отдельный security review перед каждой production release.
- Rate limit на login (Phase 2).
- Аудит критичных действий (`audit_log`).
- Bcrypt cost 12 для паролей.

### 5.4. Compliance
- **152-ФЗ**: ПДн в РФ. Согласия на обработку — версионируются (`consent_record`).
- **54-ФЗ**: чеки через сертифицированную онлайн-кассу.
- **Согласия родителей** для несовершеннолетних на видеозапись урока.
- **Право на забвение**: hard-delete по запросу с retention 30 дней soft → hard.

### 5.5. Доступность для пользователей
- WCAG 2.1 AA на ключевых экранах.
- Mobile-first для student/parent (60% траффика — телефон).
- i18n заложить с MVP; UI на старте — RU.

### 5.6. Масштабируемость
- Stateless backend, горизонтальное масштабирование.
- БД до 10 ТБ без архитектурных перестроений (партиционирование `audit_log`, `lesson_credit_ledger`).
- Видео-нагрузка масштабируется через LiveKit cluster.

## 7. Риски

| Риск                                        | Вероятн.   | Митигация                                                    |
|---------------------------------------------|------------|--------------------------------------------------------------|
| Учителя не примут систему                   | Высокая    | Early adopters 2 филиала, обучение, UX «как в журнале»        |
| 1С-интеграция затянется                     | Высокая    | MVP — CSV импорт; REST в Phase 2                              |
| Видео-нагрузка перерасход бюджета           | Средняя    | LiveKit Cloud с биллингом по минутам, лимит группы 12         |
| ПДн детей и compliance                      | Высокая    | Хостинг в РФ, согласия, аудит юристом до prod                  |
| Запись уроков и согласия                    | Средняя    | Двойное согласие (студент + родитель), retention-политика     |
| Длинный цикл закупки 1С интегратора         | Высокая    | RFP в неделю 1, параллельно с разработкой                     |

## 8. Допущения и ограничения

- Хостинг — Yandex Cloud (РФ), не AWS/GCP.
- Online cash для 54-ФЗ — на стороне эквайер-партнёра.
- Браузеры: Chrome 110+, Safari 16+, Firefox 110+, Edge 110+.
- Mobile OS: iOS 15+, Android 9+.
