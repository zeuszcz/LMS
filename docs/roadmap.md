### Метрики успеха MVP

- 5 филиалов в проде.
- ≥70% преподавателей пользуются журналом ежедневно.
- NPS родителей ≥40.
- ≤3 P1-инцидента в неделю после go-live.
- Coverage ≥70% на critical zones.

## Фаза 2 — 12 недель

### Цель

Закрыть оплаты, перевести онлайн-уроки внутрь платформы, добавить мобильный опыт.

### Эпики

1. **Эквайринг + абонементы** (4 нед)
   - YooKassa интеграция, recurring, refund flow.
   - Lesson credit ledger.
   - Cancellation policy `<24h`.
   - Receipt 54-FZ.

2. **1С двусторонняя интеграция** (3 нед)
   - REST API клиент.
   - Webhook на платежи.
   - Nightly sync students/subscriptions.

3. **Видеоуроки на LiveKit** (3 нед)
   - Self-hosted кластер в Yandex Cloud.
   - Frontend SDK интеграция.
   - Server-side recording + S3 retention.
   - Consent-flow перед стартом.

4. **PWA** (1.5 нед)
   - Service worker, install prompt.
   - Push notifications через Web Push.
   - Offline-режим для просмотра прошлых уроков.

5. **Преподавательские шаблоны** (2 нед)
   - Банк упражнений.
   - Урок из шаблона по методике FLæʃcom.

### Бюджет: ~15 млн ₽

### Метрики успеха Phase 2

- ≥60% дистанционных уроков в платформе (а не Zoom).
- Churn оплаты −15% (благодаря recurring).
- Средний NPS родителей ≥50.

## Фаза 3 — 10 недель

### Цель

Экзаменационная подготовка и AI-усиление качества обучения.

### Эпики

1. **Mock-экзамены** (4 нед)
   - Cambridge KET/PET/FCE/CAE, IELTS, ЕГЭ/ОГЭ.
   - Таймер, anti-cheat.
   - Auto-check objective частей.

2. **AI writing feedback** (2 нед)
   - LLM с rubric-промптом.
   - Преподаватель редактирует и отправляет.
   - Метрики качества фидбека.

3. **Pronunciation scoring** (2 нед)
   - Yandex SpeechKit или Azure Speech.
   - Cambridge speaking rubric (5 параметров).

4. **Аналитика прогресса** (2 нед)
   - Тепловая карта skills.
   - Прогноз готовности к экзамену.
   - Дашборд для методиста.

### Бюджет: ~12 млн ₽

### Метрики успеха Phase 3

- ≥80% выпускников курса с подготовкой Cambridge получают целевой балл ±1.
- Время преподавателя на проверку writing −30% благодаря AI-черновику.

## Фаза 4 — 10 недель

### Цель

B2B-канал и маркетплейс летних программ.

### Эпики

1. **B2B-портал** (5 нед)
   - Multi-tenant архитектура (company-tenant).
   - SSO (SAML/OIDC).
   - Корпоративный куратор: дашборд, отчёты.
   - White-label theming.

2. **Маркетплейс летних программ** (3 нед)
   - Каталог Summer Vibes, лагерей, обучения за рубежом.
   - Онлайн-оплата с предоплатой.
   - Анкеты, согласия.

3. **Геймификация (kids)** (1.5 нед)
   - Бейджи, streak'и, лиги в группе.

4. **API для партнёров** (0.5 нед)
   - Публичный API для школ-франчайзи.

### Бюджет: ~13 млн ₽

### Метрики успеха Phase 4

- ≥3 B2B-клиента подписали контракт через портал.
- ≥30% летних программ продано через маркетплейс.
