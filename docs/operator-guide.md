## Что может каждая роль

| Роль | Может | Не может |
|------|-------|----------|
| **admin** | всё | — |
| **methodist** | создавать курсы, группы, уроки, переводить студентов, проверять заявки | удалять филиалы, менять права |
| **branch_manager** | управлять своим филиалом, преподавателями, аудиториями | редактировать чужие филиалы |

| **parent** | видеть прогресс ребёнка | взаимодействовать с уроками |

## 1. Создание филиала (admin / methodist / branch_manager)

`Сайдбар → Филиалы → + Новый филиал`

Поля:
- **Название** — `YES Митино` (внутреннее)
- **Адрес** — `Москва, ул. Митинская, 30`
- **Город** — `Москва` (используется в фильтрах)
- **Телефон** — формат `+7 925 000-00-00`
- **Часовой пояс** — `Europe/Moscow`

После создания — добавить **аудитории** (`Филиалы → <ваш> → Аудитории → +`):
- Имя, вместимость, оборудование
- Чекбокс «Онлайн-комната» — для виртуальных классов (LiveKit)

---

## 2. Создание курса (admin / methodist)

`Сайдбар → Курсы → + Создать курс`

Обязательное:
- **Название** — например, `Английский для подростков · B1`
- **Язык** — выпадающий список (en, de, fr, it, es, zh, ja, ko)
- **Уровень CEFR** — `A1 / A2 / B1 / B2 / C1 / C2`
- **Возрастная группа** — `kids / teens / adults`
- **Длительность (недель)** — `16` стандарт
- **Уроков** — `32` стандарт (2 в неделю × 16)

Опциональное:
- **Описание / Методология** — отображается на лендинге курса
- **Опубликовать** — без `published_at` курс не виден студентам

После создания — добавить:
- **Модули** (`Курс → Модули → +`) — структура программы по урокам
- **Особенности** (Cambridge, FLæʃcom, etc.)
- **Отзывы** — публикуются по одобрению методиста

---

## 3. Создание группы (admin / methodist)

`Сайдбар → Группы → + Новая группа`

Поля:
- **Курс** — выбираете из ранее созданных
- **Филиал** — для офлайн-групп; для онлайн оставить пустым
- **Преподаватель** — из списка teacher-ов (опционально, можно назначить позже)
- **Формат** — `offline / online / hybrid`
- **Дата старта** — первый урок будет от этой даты
- **Макс. студентов** — `8` стандарт, `12` для подростков

Дальше: `Группа → Расписание`, добавить **слоты**:
- День недели + время начала + продолжительность (80 мин стандарт)
- Слоты могут иметь `valid_from` / `valid_to` — для смены расписания посреди курса

После расписания — `Группа → Сгенерировать уроки` — система создаст уроки на все недели курса по слотам.

### Запись студентов
- **Через заявку**: студент жмёт «Записаться» на странице курса → методист видит в `Админка → Заявки на запись` → одобрение или отказ.
- **Вручную**: `Группа → Студенты → +` (методист добавляет студента сразу).
- **Перевод между группами**: `Группа → ⚙ Управление → Перевести студента → выбрать целевую группу`. Запись в исходной закрывается, открывается в целевой.

---

## 4. Создание урока (методист / преподаватель группы)

Уроки обычно генерируются автоматически из расписания группы, но можно создать одиночный.

`Группа → Уроки → + Новый урок` или `Сайдбар → Уроки → + Урок`

Поля:
- **Группа** — урок всегда привязан к группе
- **Sequence** — порядковый номер (1, 2, 3…)
- **Название** — `Урок 5: Past Perfect`
- **Дата и время** — `2026-05-12 19:00`
- **Длительность** — `80` минут стандарт

После создания — `Урок → Содержание (Markdown)` — методическая записка для преподавателя:
```markdown
# Урок 5: Past Perfect
## Цели
- Различать Past Simple и Past Perfect
- Уметь рассказать сюжет фильма

## Lead-in (5 мин)
Спросить «What's the most embarrassing thing you've ever done?»

## Грамматика (20 мин)
[схема Past Perfect]

## Practice (40 мин)
…
```

## 5. Перенос урока (drag-drop календарь)

`Сайдбар → Календарь` — недельная сетка.

- Тащите карточку урока на новый день / время — шаг **15 мин**.
- Урок переносится через `PATCH /api/lessons/{id}` с новым `scheduled_at`.
- Завершённые / отменённые уроки помечены полупрозрачными — их таскать нельзя.
- Кнопки `← / Эта неделя / →` сверху — переключают неделю.

Для одиночного переноса с указанием причины: `Урок → ⚙ Редактировать → Перенести` — там модалка с datetime-picker и поле `notes_for_methodist`.

---

## 6. Проведение урока (преподаватель)

Войти под teacher-ом → `Сайдбар → Уроки` → выбрать сегодняшний.

1. **Видеокласс** (если онлайн / hybrid): кнопка `🎥 Открыть видеокласс` → откроется LiveKit-комната с микрофоном и камерой. Преподаватель — admin комнаты (может мутить, кикать). Комната `lesson-<id>`.
2. **Старт урока** — `Начать урок` → статус становится `in_progress`, `actual_started_at` фиксируется.
3. **Посещаемость** — таблица студентов: `present / late / absent / excused` + балл активности 1-5.
4. **Закрытие урока** — `Завершить урок` → можно добавить заметку методисту, статус `finished`.

## 7. Домашние задания (преподаватель / методист)

`Урок → ДЗ → + Создать задание`

Типы:
- **quiz** — тест с вариантами ответов (auto_check)
- **writing** — эссе/текст (ручная проверка)
- **speaking** — аудио-ответ (студент загружает .mp3/.m4a через drag-drop)
- **reading** — чтение + ответы

Поля:
- Заголовок
- Инструкции (Markdown)
- Дедлайн (`due_at`)
- Макс. балл (10 стандарт)
- `auto_check` — для quiz

### Студент сдаёт работу
`Сайдбар → Домашки → выбрать → Сдать`

- **writing**: текстовое поле
- **speaking**: drag-drop .mp3/.m4a (через MinIO, presigned URL)
- **quiz**: радио-кнопки

### Преподаватель проверяет
`ДЗ → Работы` → выбрать → `Оценить (0-10)` + фидбек → `Сохранить`. Студент видит оценку в `Домашки → Сданные`.

---

## 8. Перевод студента между группами (методист)

`Группа → ⚙ → Управление → Перевести студента`:
1. Выбрать студента из списка активных
2. Выбрать **целевую группу** (одинаковый курс или другой уровень)
3. Нажать `Перевести`

Что происходит:
- В исходной группе `Enrollment.left_at = now()`
- В целевой создаётся новый `Enrollment` с тем же `student_id`
- Студент видит обе истории в `Профиль → Курсы`

## 9. Финансы / Платежи

В Phase 1 платежи — заглушка ([PaymentStub.tsx](../frontend/src/components/forms/PaymentStub.tsx)). Для прод-интеграции с ЮKassa: добавить ключи в `.env.prod`, реализовать webhook `/api/billing/webhook` (см. [billing.py](../backend/app/routers/billing.py)).

В админке: `Админка → Платежи` показывает invoices/payments по студенту.

## 10. Аналитика (методист / admin)

`Сайдбар → Аналитика`:
- **Overview** — total students / teachers / active groups / today's lessons
- **Timeline** — лента посещений и сдач за последние 30 дней
- **By Course** — топ курсов по выручке / заполняемости
- **By Branch** — посещаемость и активные группы по филиалам

Для своего филиала — `branch_manager` видит только свою аналитику.

---

## 11. Уведомления

Авто-отправка (через Celery worker) при:
- Одобрении / отказе в записи на курс
- Создании ДЗ
- Старте урока (за 15 мин до)
- Назначении оценки

Канал: in-app + email (через MailHog в dev, через `SMTP_*` в prod).

Студент видит в `Колокольчик` сверху → `Сайдбар → Уведомления`. Прочитанное помечается через PATCH.

## 12. Бэкап / Восстановление

```bash
# Бэкап postgres
ssh site-vps "sudo docker exec lms-postgres pg_dump -U lms lms" > lms-$(date +%F).sql

# Бэкап MinIO (загруженные файлы)
ssh site-vps "sudo docker exec lms-minio tar -cz -C /data ." > lms-media-$(date +%F).tar.gz

# Восстановление
cat lms-2026-04-28.sql | ssh site-vps "sudo docker exec -i lms-postgres psql -U lms lms"
```

Авто-бэкап рекомендуется через `cron` на хосте раз в сутки в `/var/backups/lms/`.

## 13. Сброс данных (DESTRUCTIVE)

Если нужно «начать с нуля»:

```bash
ssh site-vps "cd /opt/yes-lms/deploy && \
  sudo docker compose --env-file .env.prod -f docker-compose.prod.yml down -v && \
  sudo docker compose --env-file .env.prod -f docker-compose.prod.yml up -d && \
  sleep 15 && \
  sudo docker exec lms-backend python -m app.services.seed_yescenter"
```

Это удалит ВСЕ данные (postgres + MinIO), пересоздаст контейнеры, выполнит миграции, забутстрапит superuser-а и засеет демо-данные.
